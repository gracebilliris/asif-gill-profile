# Publishing a blog post

Asif can publish directly from the GitHub website without installing anything.

1. Open the repository's [`_posts`](https://github.com/gracebilliris/asif-gill-profile/tree/main/_posts) folder.
2. Select **Add file → Create new file**.
3. Name the file using `YYYY-MM-DD-short-title.md`, for example
   `2026-08-08-responsible-agentic-ai.md`.
4. Paste the template below and replace its example text.
5. Select **Commit changes**. GitHub Pages will publish the post automatically,
   usually within a few minutes.

```markdown
---
layout: post
title: "The title of the article"
description: "A one-sentence summary shown on the writing page."
category: Human-centred AI
date: 2026-08-08
---

Opening paragraph.

## First section

Article content goes here.

## Second section

More content goes here.
```

Use `##` for section headings, blank lines between paragraphs, `-` for bullet
lists, and `[link text](https://example.com)` for links. The writing index,
article styling and navigation are generated automatically.
